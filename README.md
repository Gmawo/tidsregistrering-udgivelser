# Websubstans Tidsregistrering: udgivelser

Færdigbyggede udgaver af macOS-appen **Tidsregistrering**. Her ligger kun appen og en versionsfil (`appcast.json`), som appen bruger til at opdatere sig selv. Ingen kildekode og ingen kundedata.

**Hent seneste version:** [Releases → Latest](../../releases/latest), hent `Tidsregistrering.zip`, og træk appen til mappen Programmer.

Første gang advarer macOS om en ukendt udvikler. Højreklik på appen og vælg Åbn (macOS 14 og ældre), eller vælg Åbn alligevel under Systemindstillinger → Anonymitet og sikkerhed (macOS 15 og nyere). Derefter opdaterer appen sig selv.
